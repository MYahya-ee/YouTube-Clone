# YouTube Clone

A static recreation of YouTube’s homepage built with **HTML and CSS**, featuring a dark theme, video thumbnails, channel information, and video metadata.

## Features

- YouTube-inspired dark theme
- Search bar UI
- Six video cards in a three-column grid
- Video thumbnails with rounded corners
- Channel profile images and verification icons
- Video titles, creator names, view counts, and upload dates
- Local and externally hosted images

## Tech Stack

- HTML5
- CSS3

## Getting Started

**1. Clone the repository**

```bash
git clone <repository-url>
```

**2. Navigate to the project directory**

```bash
cd YouTube-Clone
```

**3. Run the project**

Open `youtube.html` in your browser, or use the **Live Server** extension in VS Code.
